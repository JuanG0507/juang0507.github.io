# Portafolio personal — Juan José Gutiérrez

Primera propuesta visual de una página personal para presentar perfil, formación, habilidades y proyectos seleccionados.

## Vista previa

Abre `index.html` en un navegador. No requiere instalar dependencias ni compilar.

## Archivos

- `index.html`: estructura y contenido editable.
- `styles.css`: diseño adaptable a móviles y escritorio.
- `script.js`: navegación móvil y filtros de proyectos.

Esta versión usa la información pública del perfil de GitHub como base. Formación, habilidades y proyectos se pueden actualizar cuando haya datos nuevos.
